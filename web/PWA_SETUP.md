# PWA Setup for PragueGTA

This document describes the Progressive Web App (PWA) capabilities added to PragueGTA to improve mobile performance and enable installation on devices.

## Features Added

### 1. Web App Manifest
- **Location**: Automatically generated by `vite-plugin-pwa`
- **Configuration**: See `vite.config.ts`
- Defines app name, icons, theme colors, and display mode
- Enables "Add to Home Screen" functionality on mobile devices

### 2. Service Worker
- **Type**: Workbox-based service worker (auto-generated by vite-plugin-pwa)
- **Strategy**: 
  - CacheFirst for game assets (3D models, audio files)
  - CacheFirst for fonts and static resources
  - Runtime caching for better offline support
- Automatically updates when new versions are deployed

### 3. App Icons
- **Location**: `web/public/icons/`
- **Generation**: Run `node generate-icons.js` to regenerate icons
- SVG-based icons for scalability
- Multiple sizes (72x72 to 512x512) for different devices
- Supports both regular and maskable icons

### 4. Install Prompt
- **Component**: `src/view/PwaInstallPrompt.vue`
- Appears after 3 seconds on first visit
- Can be dismissed (dismissal is stored)
- Only shows if the app is not already installed
- Provides native install experience

### 5. Mobile Optimizations
- Standalone display mode (full-screen without browser UI)
- Theme color matches app design
- Proper viewport configuration
- Apple Touch Icon support
- Microsoft Tile support

## Benefits

### For Users
1. **Install to Home Screen**: Users can install the app like a native app
2. **Offline Support**: Core assets are cached for offline play
3. **Better Performance**: Cached resources load instantly
4. **More Resources**: Standalone mode provides more screen space and better resource access
5. **Native Feel**: Runs without browser UI, feels like a native app

### For Development
1. **Automatic Updates**: Service worker updates automatically
2. **Easy Maintenance**: Icons are generated from a simple script
3. **Type-Safe**: Full TypeScript support
4. **Dev Mode**: PWA works even in development mode

## Testing PWA

### Local Testing
```bash
cd web
npm run build
npm run preview
```

Then open the preview URL on a mobile device or use Chrome DevTools:
1. Open Chrome DevTools
2. Go to Application tab
3. Check "Manifest" and "Service Workers"
4. Use Lighthouse to audit PWA score

### Production Testing
1. Deploy the app
2. Open on a mobile device
3. Browser will show "Install App" banner
4. Or use browser menu → "Install App" / "Add to Home Screen"

## Customization

### Updating Icons
1. Replace the icon generation logic in `generate-icons.js`
2. Or manually create PNG icons in `public/icons/`
3. Update icon references in `vite.config.ts` manifest section

### Changing Colors
Update theme colors in:
- `vite.config.ts` (manifest `theme_color` and `background_color`)
- `index.html` (meta `theme-color`)

### Modifying Cache Strategy
Edit the `workbox` section in `vite.config.ts`:
- Add new URL patterns to `runtimeCaching`
- Adjust cache expiration times
- Change caching strategies (CacheFirst, NetworkFirst, etc.)

## Deployment Notes

1. PWA requires HTTPS (except localhost)
2. Service worker scope is from the root `/`
3. Icons and manifest are automatically included in build
4. No additional server configuration needed
